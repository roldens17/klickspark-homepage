01

What’s in the box

  • PACE theme zip for Volt (the default, and the look in the listing hero), plus separate zips for Ember and Glacier
  • This buyer guide (PDF)
  • Spec tag cheat sheet with copy-paste examples
  • Bonus AI photo pack: 25 original demo photos, plus 17 cool-grey retouches of the product and Studio tile shots (recommended if you use Volt). No stock photography.
  • Changelog and a single-store license

The theme zip does not include the demo store’s products, collections or uploaded images. After install, sections that need a product, collection or image show placeholders until you add your own.

PACE works on any Shopify plan that supports Online Store 2.0. No apps are required for the features in this guide.

02

Install from the zip

  1. In your download, pick the zip for the preset you want (Volt, Ember or Glacier). Upload that zip rather than switching presets later; each zip is already set to its preset colours and fonts.
  2. In Shopify, go to Online Store > Themes.
  3. Click Add theme, then Upload zip file, and select the zip.
  4. When the theme appears in your library, click Preview and walk the home, collection, product, cart and search pages.
  5. Click Customize to set your logo, menus, homepage collections and images (the steps below).
  6. When it looks right, click Publish.

After you upload

  • Header > Logo text is set to PACE in the shipped header. Replace it with your brand, or upload a Logo image and set Logo width desktop / Logo width mobile.
  • Header > Main menu defaults to the Shopify menu called main-menu. Point it at your own navigation, or edit that menu under Online Store > Navigation.
  • Create your collections and products first, then hook them into PACE activity tiles, PACE product grid, PACE hero and PACE spec sheet.
  • Add your social URLs under Theme settings > Social links so the footer Social block can show icons.

If you are replacing another theme

PACE will not import another theme’s section settings. Publish only after you have set your logo, menus and homepage. Keep the old theme unpublished until you have previewed checkout, policies and the password page (if your store is hidden).

06

Mega menu

The desktop mega menu is driven by your navigation menu, plus optional promo tiles in the header.

It appears at 1024 px and wider. Below that, the desktop panel is hidden and the Mobile menu type is used instead (Drawer, Overlay or Inline; default Drawer).

Build the menu

  1. Go to Online Store > Navigation and edit the menu selected in Header > Main menu (default main-menu).
  2. The top-level item is the link in the header, for example Shop.
  3. Children of that item become columns. The child’s title is the column heading and links to the child’s URL.
  4. Grandchildren of that item become the links under the column.

A top-level item opens a mega panel when it has at least one child, or when at least one Mega menu promo block targets it.

A child with no grandchildren still shows as a column with only its heading link.

Add promo tiles

In the theme editor, open the Header section and add a Mega menu promo block (up to 12 header blocks total).

  • Menu item title — must match the top-level link title in Navigation, for example Shop. The match is not case-sensitive, but the wording must be the same.
  • Image
  • Heading — default New this week.
  • Link — leave empty to use the menu item’s own link.
  • Button text — optional.

Up to 2 promo tiles show for each top-level item. Extra blocks for the same item are ignored. Promo tiles do not appear in the mobile menu.

Keyboard and behaviour

  • Hover, or moving focus onto the item, opens the panel.
  • Enter or Space on the panel’s toggle button, or Space on the top-level link, opens the panel and moves focus into it.
  • Down arrow on the link or the toggle does the same.
  • Escape closes the panel and returns focus to the top-level link.
  • Quick View and the popup cart open above the panel.

Other useful header settings

  • Enable sticky header and Enable sticky header on mobile
  • Hide sticky header on scroll down
  • Color scheme — Dark, Light or Custom. Light uses the theme’s paper background and ink text; Dark is the inverse. Custom uses Custom background, Custom text, Custom link color and Custom hover color, plus the header’s own Announcement background and Announcement text.
  • Show announcement bar, Promo text, Promo link, Promo link label
  • Hide announcement on mobile, Announcement text size, Announcement vertical padding
  • Secondary header text, Featured link label, Featured link
  • Enable search panel, Search heading, Search placeholder, Search help text
  • Show wishlist icon — decorative only. Connect a wishlist app to save items.
  • Cart icon style — Cart or Shopping bag.
  • Utility menu — optional extra links.

The announcement bar only shows when Show announcement bar is on and Promo text is not empty. If Add run trial to the announcement bar is on, the run trial title is appended to the promo text.

07

Spec and stat tags

This is PACE’s signature feature. Add tags to a product and the theme draws rating bars and stat boxes on the product page (PACE product specs) and on the homepage (PACE spec sheet). No app and no code.

Tag format

TypePatternExampleResult
Rating barspec:Name:Nspec:Cushion:4A bar labelled Cushion, scored 4 / 5
Stat boxstat:Name:valuestat:Weight:212 gA box labelled Weight, value 212 g

Rules:

  • Use exactly two colons. The theme splits each tag on : and ignores anything that does not have three parts.
  • Name is the label customers see (for example Cushion or Weight).
  • For spec: tags, N is a whole number from 1 to 5. Values are clamped to that range.
  • For stat: tags, the value may contain spaces (6 mm, 198 g) but must not contain a colon.
  • spec and stat are not case-sensitive (SPEC:Cushion:4 works). The label is shown as you typed it.
  • Tags are shown in the order Shopify returns them, which is alphabetical.

Copy-paste set, as used on the demo Metro Runner:

spec:Cushion:3
spec:Grip:4
spec:Responsiveness:5
spec:Stability:3
stat:Drop:6 mm
stat:Stack:32 mm
stat:Weight:198 g

To add them: open the product in Shopify, find Tags, paste each tag, and save.

Optional metafield override

If you set a product metafield named custom.pace_specs (JSON), and it contains any bars or stats, the theme uses that metafield and ignores the tags for that product.

Example value:

{
  "bars": [{ "label": "Cushion", "score": 3 }],
  "stats": [{ "label": "Drop", "value": "6 mm" }]
}

score can also be sent as value. This metafield is optional. Most stores only need tags.

PACE product specs (product page)

This section is available on product templates.

  • The editor note in the section reads: specs come from custom.pace_specs if set, otherwise from product tags.
  • Eyebrow — default Spec sheet.
  • Heading — default Built to move.
  • Text when a product has no spec tags — shown when the product has neither metafield data nor tags.
  • Open the first detail — default on.

Detail blocks (accordion rows under the specs):

  • Title and Content
  • Add run trial — adds the title and text from Theme settings > Run trial. Hidden when the run trial is off.
  • Add refund policy link — only shows when a refund policy is published in Settings > Policies.

The shipped product template includes three details: Fit notes, Shipping & returns (with run trial and refund link on) and Care. Edit the copy to match your store. Only list policies and shipping times that are actually true for you.

08

Shop by Activity tiles and collections

The PACE activity tiles section is the Shop by Activity grid on the homepage.

Section settings

  • Heading — default Shop by on one line and activity on the next (you can type a line break in the field).
  • Count label — default Categories. The section prefixes the visible tile count, for example 04 Categories.

Each Tile block

You can add up to 6 tiles. The shipped homepage is set up for four: Run, Train, Recover and Studio.

  • Collection — the tile links here. Leave this empty and clear Link to hide the tile on the live store. In the editor, an unset tile stays visible but dimmed, with a note.
  • Image — leave empty to use the collection image.
  • Title — leave empty to use the collection title.
  • Link — optional. Only used when no collection is picked.

The whole section hides on the live store when no tile has a collection or a link.

How many columns you will see

The grid uses one column per visible tile, with a minimum of 2 and a maximum of 4:

  • 2 visible tiles → 2 columns
  • 3 visible tiles → 3 columns
  • 4, 5 or 6 visible tiles → 4 columns (the fifth and sixth wrap to the next row)

If you expected four columns and only see two, the Recover and Studio tiles (or whichever are missing) do not have a collection or a link yet.

Set up the four demo-style tiles

  1. In Shopify, create a collection for each activity (manual or automated), for example Run, Train, Recover and Studio, and add the right products to each.
  2. Optional: add a collection image, or you can pick an image on the tile itself.
  3. In Customize, open PACE activity tiles. For each Tile, pick the matching Collection. Set Title only if you want wording that differs from the collection name.
  4. Save and preview the homepage. You should see four columns, and each tile should open its collection.

Size guide

The size guide is a dialog on the product page, opened by a link next to a variant option (usually Size). Escape closes it and returns focus to the link.

Which guide a product gets

The theme picks a guide in this order:

  1. A product metafield custom.size_guide that references a page. If set, this always wins.
  2. If the product is footwear — its product type is listed in Footwear product types, or it is tagged footwear / Footwear:

- the Footwear size guide page, if one is selected, otherwise

- the Footwear guide title and Footwear guide text from theme settings.

  1. For every other product: the Size guide page selected on the Main product section.

The link is hidden when no guide content applies, even if Show size guide link is on.

Theme settings > Size guide

  • Footwear product types — default Shoes, Footwear, Sneakers. Comma-separated. Products of these types, or tagged footwear, use the footwear guide.
  • Footwear size guide page — optional. Leave empty to use the footwear text below.
  • Footwear guide title — default Footwear size guide.
  • Footwear guide text — default copy explains a true-to-size fit and how to measure. Clear this (and leave the footwear page empty) to hide the size guide on footwear that do not have a metafield page.
  • Add a between-sizes tip for footwear — default on. Adds a tip to pick the next whole size when only whole sizes are sold, or the next half size when half sizes exist, based on the product’s actual Size values.

Main product section (product page)

Under the Size guide header:

  • Show size guide link — default on.
  • Size guide page — create a page under Online Store > Pages with your apparel size chart, then pick it here. This is the guide for non-footwear products. The shipped theme looks for a page with the handle size-guide; if that page does not exist in your store, select your own page.
  • Show the link next to the option named — default Size. The link appears beside the option whose name matches this text.

Only list fit advice that is true for your products. The default footwear text is a starting point, not a claim about your inventory.

Drop countdown

The homepage uses the PACE drop section.

Launch time

  • Launch date — YYYY-MM-DD, default 2026-12-12. Leave empty for an email signup with no countdown.
  • Launch time — 24-hour HH:MM in the time zone below, default 09:00.
  • UTC offset — the offset of the launch time zone on launch day, for example -05:00 for New York in winter or -04:00 in summer. Default -05:00. Type it carefully; this field is plain text.
  • Time zone label — default ET. Shown after the launch time. Leave empty to show the UTC offset instead.

If the date or time is missing or invalid, the countdown and the launch line are hidden. The rest of the section still shows.

The launch line is built from the date, time and label you entered. It does not convert time zones for the shopper’s location.

Before and after launch

  • Eyebrow, Heading line 1, Heading line 2
  • Background image — optional. Without an image, the section uses the button colour.
  • Image overlay — 0–90%, default 55%.
  • After launch — Show live message (default) or Hide this section.
  • Live message — default Live now.
  • Live button label — default Shop the drop.
  • Live button link — the button only shows when a link is set.
  • Link anchor — default drop. Link to this section with /#drop (the demo header featured link uses this).
  • Show email signup — default on. This is Shopify’s customer/newsletter form, not a third-party app.
  • Email placeholder, Button label, Success message

Another countdown section

The theme also includes a section named Drop countdown (an older layout, with a time-zone dropdown and separate before/after button labels). The homepage uses PACE drop. You can add Drop countdown to other pages if you prefer that layout. Do not put both on the same page unless you mean to show two timers.

11

Popup cart, Quick View and search

Popup cart

Clicking the cart icon in the header opens the popup cart (not a full-page jump). Shoppers can change quantities, remove lines, and go to checkout from there. A full cart page still exists if someone visits /cart.

Related settings, under Theme settings > Theme behavior:

  • Enable popup cart recommendations
  • Show free shipping progress bar in cart
  • Free shipping threshold

The progress bar compares the cart subtotal with that threshold. It will confuse shoppers if your real free-shipping rate in Settings > Shipping and delivery is a different amount, so keep them in sync.

Escape closes the popup cart. The header Cart icon style can be Cart or Shopping bag.

Quick View

When Enable quick view is on, product cards can open a Quick View dialog so shoppers can pick a variant and add to the popup cart without leaving the grid. Escape closes Quick View.

Search

Header > Enable search panel turns on the header search. Predictive search is built in. The collection and search result pages can show storefront filters when Enable storefront filters (collection) or Show filters on search results (search) is on. Filters use Shopify’s storefront filtering; set them up under Settings > Search & Discovery if your shop’s plan supports it.

Product page

The shipped product template is, from top to bottom:

  1. Main product — media, title, price, variants, add to cart, size guide link, trust badges.
  2. PACE product specs — rating bars, stat boxes and detail accordion (see section 7).
  3. Product recommendations — You may also like (related products).
  4. Product recommendations — Pairs well with (complementary products). Complementary recommendations need to be set up in Settings > Search & Discovery.

Main product settings

  • Enable sticky add to cart (mobile) — default on. A sticky bar on small screens. Desktop sticky add-to-cart is not in this version.
  • "Part of ... Collection" label — Automatic or Hide. Automatic shows one real category collection. It skips the collections listed below, sale collections, and men/women when a product is in both.
  • Collections to skip in the label — default all, frontpage, new-arrivals, best-sellers, sale. Use collection handles, separated by commas.
  • Show vendor or product type, Show price, Show description, Show dynamic checkout buttons
  • Size guide settings — see section 9.
  • Show back-in-stock signup on sold-out variants — default on. Signups are saved in Customers with the tags back-in-stock and the product handle. Email those customers when you restock.
  • Show low stock message — default off. Uses real inventory. Only appears for variants tracked by Shopify with stock at or below Low stock threshold (default 5).
  • Show custom note under add to cart and Custom note text — static text on every product. Only use statements that are true for your store.
  • Show trust notes under sticky add to cart
  • Show trust badges row, plus optional Shipping, Returns and Warranty badges and their promise text. Returns link can be left empty to use your refund policy from Settings > Policies.

Blocks you can add on Main product:

  • App blocks
  • Collapsible info tab — Heading, Content, Open by default
  • Custom Liquid

Sold-out variants are still shown and cannot be added to the cart. The back-in-stock form appears when that setting is on.

FAQ page

PACE includes a product-page-style FAQ section and a page template that already has it.

To publish an FAQ page:

  1. Go to Online Store > Pages and create a page (for example titled FAQ, which gives the handle faq and the URL /pages/faq).
  2. In the page’s Theme template list, choose the faq template.
  3. Click Save, then Customize the page to edit the questions.

The FAQ section settings include:

  • Show section, Heading, Subheading, Description, Text alignment
  • Color scheme — Light, Dark or Custom
  • Layout mode — Accordion, or Two-column accordion
  • Open first item by default, Show expand/collapse controls
  • Spacing, type sizes and control-button styles

Each FAQ item block has a Question and an Answer (rich text). The section allows up to 16 items.

The shipped template includes four starter questions (shipping, returns, size, international shipping). Rewrite them so they match your policies. A /pages/faq URL will 404 until you create the page and assign the template.

You can also add the FAQ section to any other page or to the homepage.

Troubleshooting

The Shop by Activity grid is 2 columns, not 4.
A tile only counts when it has a Collection or a Link. Create the missing collections, pick them on the Recover and Studio tiles (or your equivalent), and save. See section 8.

Spec bars or stats do not show.
Check the tag has exactly two colons (spec:Cushion:4, not spec:Cushion 4). Scores must be a number. Stat values cannot contain a colon. If custom.pace_specs is set and has any bars or stats, tags are ignored. On the homepage, confirm PACE spec sheet has a Product picked and Use the product's specs is on.

The size guide link is missing.
The link only shows when there is guide content. For footwear, set Footwear guide text or a Footwear size guide page, or tag the product footwear / set its product type to one of the types in the list. For apparel, pick a Size guide page on the Main product section. A custom.size_guide metafield, if used, must reference a page that has content.

Mega menu promo tiles do not appear.
Menu item title must match the top-level navigation title (for example Shop). Up to two tiles per item are used. On desktop (1024 px and wider) they appear in the mega panel; on smaller screens they appear in the mobile drawer when that menu item is expanded.

The announcement bar colours look wrong for Ember or Glacier.
Each preset zip sets its own announcement bar colours (Ember #1A1714 / #EDE8DF, Glacier #0E1A2B / #EEF3F8). If you uploaded a different zip or changed colours later, set Announcement bar background and Announcement bar text in Theme settings > Colors to those values, or upload the preset zip you want.

The header logo still says PACE (or, on a reset block, a default brand name).
Set Header > Logo text or upload a Logo image.

/pages/faq is a 404.
Create a page and assign the faq template. The template is in the theme; the page has to exist in the store.

Quick View or the popup cart does not open.
Confirm Enable quick view and that you are clicking a card’s Quick View control or the header cart icon. Try a hard refresh after publishing.

The free shipping bar does not show, or the amount looks wrong.
Turn on Show free shipping progress bar in cart, and set Free shipping threshold to the same amount as your shipping rate.

Search cannot find a product.
The product must be active and available in the Online Store channel. Shopify search uses the product title, tags and other storefront search fields from Settings > Search & Discovery.

The theme does not look like the demo after a clean install.
That is expected until you add products, photos and collections, and pick them in the hero, activity tiles, spec sheet and product grid. The layout and colours of the preset you installed should already match. If you uploaded Volt and wanted Ember, upload the Ember zip.

I need a second store.
The license is one store per purchase. Buy a second license for a second store, or contact support if you are unsure.
